# NorthStar

The Astrisk mark: an eight-point north star (four long rays, four short) inside a thin orbit ring.

## Usage

Use as the brand emblem, in empty states and on sign-in. `ring={false}` for tight spaces. Default color is the gold accent; pass `title` when it is meaningful, otherwise it is hidden from screen readers. Never recolour it with planet colours.

```tsx
<NorthStar size={40} />
```
