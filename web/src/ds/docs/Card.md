# Card

The surface for grouped content, with optional title, sub-title and header actions.

## Usage

`tight` for dense side panels, `flush` when the content (tables, charts) supplies its own padding. Use `as="article"` for feed items. Do not nest cards.

```tsx
<Card title="Current dasha" sub="Vimshottari">...</Card>
```
