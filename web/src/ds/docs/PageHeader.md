# PageHeader

Page title block: optional kicker, h1 title, description and right-aligned actions.

## Usage

One per page, at the top. Kicker names the section, title names the thing. `compactOnMobile` hides the description on phones.

```tsx
<PageHeader kicker="Kundali" title="Ananya Rao" actions={<Button>Edit</Button>} />
```
